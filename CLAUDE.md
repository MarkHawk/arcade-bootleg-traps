# Rules for this repo

## TCRF (tcrf.net)

TCRF does not allow automated or AI access, so it is not fetched by any tool or script here. Never fetch any tcrf.net page, by any tool or
script (WebFetch, curl, Python, a subagent, a browser tool), and do not try mirrors, archives or proxies. Linking to
TCRF in the docs is fine. Link checkers must skip tcrf.net links and list them as "not checked, by request".

## robotron-2084.co.uk

Don't link to or fetch robotron-2084.co.uk (the owner's request, to save bandwidth); credit it as plain text. No tool or script fetches it, and
scripts/linkcheck.py fails on any link or URL to it.

Before adding or changing a game section, read docs/STYLE.md and follow it, including the checklist.
